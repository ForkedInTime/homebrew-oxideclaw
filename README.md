# Homebrew tap for OxideClaw

```bash
brew install ForkedInTime/oxideclaw/oxideclaw
# or
brew tap ForkedInTime/oxideclaw && brew install oxideclaw
```

Installs the prebuilt release binary for macOS (Apple Silicon, Intel) and
Linux (x86_64, arm64), verified against the SHA-256 published with each
release, plus shell completions.

The formula's source of truth is `contrib/homebrew/oxideclaw.rb` in
[ForkedInTime/OxideClaw](https://github.com/ForkedInTime/OxideClaw); it is
copied here on every release.
