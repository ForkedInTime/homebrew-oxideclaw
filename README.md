# Homebrew tap for RustyClaw

```bash
brew install ForkedInTime/rustyclaw/rustyclaw
# or
brew tap ForkedInTime/rustyclaw && brew install rustyclaw
```

Installs the prebuilt release binary for macOS (Apple Silicon, Intel) and
Linux (x86_64, arm64), verified against the SHA-256 published with each
release, plus shell completions.

The formula's source of truth is `contrib/homebrew/rustyclaw.rb` in
[ForkedInTime/RustyClaw](https://github.com/ForkedInTime/RustyClaw); it is
copied here on every release.
